# Especificações

Cada capacidade recebe uma pasta com identificador sequencial e nome curto, como `001-tela-de-acesso`.

Uma especificação deve registrar objetivo, escopo, requisitos, regras de negócio, critérios de aceite e itens fora de escopo. Dados e decisões técnicas específicos podem ser mantidos em arquivos complementares dentro da mesma pasta.
